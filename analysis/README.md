# analysis

Figure and table scripts. Run from the repository root. Every script reads from `data/processed/`
(layout in `data/README.md`) and writes to `figures/`. Directory READMEs give the panels, inputs,
run order and caches.

| Directory | Manuscript items |
|---|---|
| `fig1_ambient_contamination/` | Fig. 1B to I |
| `fig2_ambientmapper_framework/` | Fig. 2B to E |
| `fig3_decontamination/` | Fig. 3A to E |
| `fig4_robustness/` | Fig. 4A to N |
| `fig5_biological_impact/` | Fig. 5A to L |
| `supplementary/` | Fig. S1, S2, S3, S5, S6, S7, S8 (S4 is a schematic) |
| `tables/` | Tables S1 to S4 |
| `_helpers/` | palettes, themes and functions sourced by the scripts above |

Fig. 1A, Fig. 2A and Fig. S4 are drawn by hand and have no script.
