# AmbientMapper manuscript

Companion repository for

> **Empirical Estimation of Ambient Contamination in Combinatorial Single-Cell Methods Using Multi-Reference Mapping.** Fabio Gomez-Cano, Luguang Jiang, Joshua D. Welch, Alexandre P. Marand. bioRxiv (2026). https://doi.org/10.64898/2026.09.11.750809

This repository holds the code behind every figure, supplementary figure and supplementary table of the manuscript, and the pipeline scripts that produced their inputs. It is not the software tool itself.

## What is here

```
analysis/        one directory per main figure, plus supplementary/ and tables/. Visualisation only:
                 every script reads pre-computed tables from data/processed/ and writes to figures/.
analysis/_helpers/  shared palettes, themes and helper functions sourced by the figure scripts
workflows/       the pipeline that produced those tables, in execution order:
                 01_preprocessing -> 02_mapping -> 03_genotyping (and 03b_variant_based_comparison)
                 -> 04_decontamination -> 05_qc_and_embedding
config/          plate designs, pool files, genome lists, run plans and the AmbientMapper
                 configuration of every run reported in the paper
data/            metadata (tracked), and the expected layout of data/processed/ (not tracked)
figures/         output directory of the analysis scripts (empty in git)
SOFTWARE_VERSIONS.md  every tool version used, with the evidence it was read from
```

Each directory has its own README listing its scripts, the manuscript panels they produce, the
inputs they read and the order to run them in.

## How to reproduce a figure

1. Create the environment: `conda env create -f environment.yml && conda activate ambientmapper-manuscript`.
   The meta-cell step uses a separate SEACells environment, see `workflows/05_qc_and_embedding/README.md`.
2. Place the processed inputs under `data/processed/` following the layout in `data/README.md`.
   These tables are the outputs of `workflows/`; the maize and Arabidopsis library is deposited in
   GEO (accession above) and the public libraries are in SRA (table below).
3. Run the figure script from the repository root, for example
   `Rscript analysis/fig2_ambientmapper_framework/fig2.R`. Scripts that need a cache produced by a
   sibling script say so in their directory README.

Panels drawn by hand (Fig. 1A, Fig. 2A, Fig. S4) have no script. Final figures were assembled from
the per-panel PDFs in Illustrator, so panel letters in output file names follow the manuscript.

### Dataset names in scripts, configs and paths

Scripts, configuration files and directory names keep the identifiers of the analysis pipeline, so
that they match the run logs and the layout under `data/processed/`.

| Name in this repository | Library |
|---|---|
| `SM2` | maize and Arabidopsis scifi-ATAC library, reads mapped to the concatenated maize + Arabidopsis reference |
| `SM2v2` | the same library, reads mapped to each genome independently (the multi-reference input of AmbientMapper) |
| `Root1_rep1` | 10x scATAC-seq maize B73 root (Marand et al. 2021) |
| `B73Mo17_rep1`, `B73Mo17_rep2` | scifi-ATAC B73 and Mo17, replicates 1 and 2 (Zhang et al. 2024) |
| `multiGenotypes_rep1` | scifi-ATAC seven-genotype pool (Zhang et al. 2024) |
| `synthetic`, `synthetic_disc` | read-level synthetic benchmark, all peaks and discriminative peaks |

Both `SM2` names refer to the single library generated in this study. The data records use the names
`AtZm_scifiATAC_combinedRef`, `AtZm_scifiATAC_indepRef`, `ZmRoot_scATAC`, `B73Mo17_scifiATAC_rep1`,
`B73Mo17_scifiATAC_rep2` and `multiGenotype_scifiATAC` for the same datasets.

## Pipeline

```
raw FASTQ
  -> 01_preprocessing   scifi-demux step 1 (Zhang libraries), legacy UMI-tools/cutadapt/Perl chain (maize+Arabidopsis and root libraries)
  -> 02_mapping         BWA-MEM to every candidate reference, barcode-corrected, deduplicated BAMs, Tn5 insertion BEDs
  -> 03_genotyping      AmbientMapper extract -> filter -> assign -> genotyping; 03b: Souporcell v2.1 and WASP allele purity
  -> 04_decontamination AmbientMapper decontam (with design, WD, and without design, ND) and clean-bams
  -> 05_qc_and_embedding Socrates QC, SVD, UMAP, Leiden clustering, co-embedding, SEACells meta-cells, marker annotation
  -> analysis/          figure and table scripts
```
